### Overview

UAEprop is a comprehensive real estate platform designed to streamline property discovery and listing management. Built with a modern tech stack centered on Next.js and Node.js, it offers a high-performance experience for users looking to buy, sell, or rent properties. The platform emphasizes visual quality and security, utilizing robust backend services for data and media management.

**Technologies**: Next.js 16, React 19, Node.js, Express, MongoDB, Cloudinary, Tailwind CSS  
**Project Type**: Real Estate Marketplace / Full-Stack Web App

### Key Features

- **Advanced Property Listing**: Users can list properties with detailed metadata and up to 10 high-resolution images.
- **Cloudinary Integration**: Fully automated image pipeline for uploading, optimizing, and resizing property and profile photos.
- **Secure Authentication**: Multi-layered security using JWT access tokens and long-lived refresh tokens with rotation.
- **Interactive User Profiles**: Customizable user profiles including automated face detection for profile pictures.
- **Robust Search & Filtering**: Efficient property search based on location, property type, and specific amenities.

### Role & Contributions

- **Full-Stack Development**: Engineered the core property management system from frontend UI to backend REST APIs.
- **Media Pipeline Architecture**: Designed and implemented the entire Cloudinary/Multer integration for reliable image storage and retrieval.
- **API Security**: Developed secure authentication flows and RBAC to protect user and property data.
- **Modern UI Implementation**: Crafted a responsive, mobile-first interface using Tailwind CSS 4 and Lucide icons.

### Impact

- **Visual Excellence**: Achieved significant improvements in page load speed through automated image optimization.
- **User Trust**: Implemented strict validation and secure auth, leading to a safer marketplace environment.
- **Scalability**: Designed the backend with a modular approach, allowing for easy expansion of feature sets.
