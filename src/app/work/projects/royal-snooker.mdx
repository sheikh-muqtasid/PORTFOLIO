### The Problem

Snooker clubs often struggle with manual table tracking, leading to overbooking and revenue leakage. Managing member dues and tracking snack/drink sales alongside game fees creates significant administrative overhead.

### The Solution

**Royal Snooker** provides a unified dashboard for club owners. Built with the MERN stack, it features a real-time table occupancy grid and an integrated Point of Sale (POS) system tailored for club environments.

### Key Features

- **Real-time Table Grid**: A live view of all tables, showing occupancy status and elapsed time for active games.
- **Member Management**: Track subscriptions, member loyalty levels, and automate due payment reminders.
- **Integrated POS**: Seamlessly combine game fees with snack and beverage sales into a single invoice.
- **Financial Analytics**: In-depth reporting on daily revenue, peak hours, and popular services.

### Tech Stack

- **Frontend**: React, Next.js, Material UI, Redux
- **Backend**: Node.js, Express, JWT Authentication
- **Database**: MongoDB (Complex aggregation for financials)

### My Role

I led the full-stack development, specifically focusing on the double-player payment logic and the real-time update system. I optimized the backend rate limits to ensure stability during peak club hours and modernized the entire UI for better accessibility.
