### Overview

QRPlate.pk is a B2B SaaS platform designed to modernize the dining experience for Pakistani restaurants. By providing free QR-based digital menus and easy-to-manage deal systems, it eliminates printing costs and simplifies menu management without the complexity of traditional delivery systems.

**Technologies**: Next.js (App Router), Node.js, Express, MongoDB, Cloudinary, JWT  
**Project Type**: B2B SaaS / Digital Menu System

### Key Features

- **Dynamic QR Menus**: Instant menu updates via QR scan without reprinting physical materials.
- **Smart Deal System**: Automated deal tracking with countdown timers and expiry logic.
- **Freemium Implementation**: Multi-tier plan enforcement (Free vs Pro) managed via custom middleware.
- **Analytics Dashboard (Pro)**: Real-time tracking of menu views, deal clicks, and traffic patterns.
- **Multi-Branch Management**: Scalable architecture supporting multiple locations for a single restaurant owner.

### Role & Contributions

- **System Architecture**: Designed a modular monolith architecture with Next.js and Node.js.
- **API Development**: Built robust REST APIs with JWT authentication and RBAC (Super Admin, Owner).
- **Plan Enforcement**: Implemented dynamic plan-based middleware to manage usage limits (branches, items, deals).
- **Public Menu SSR**: Leveraged Next.js Server-Side Rendering for SEO-optimized and fast-loading public menus.

### Impact

- **Operational Efficiency**: Drastically reduced menu printing costs for early pilot restaurants.
- **Market Fit**: Designed specifically for the Pakistani market, addressing local pain points like high delivery commissions.
- **Scalability**: Architecture designed to support over 10,000 restaurants with optimized database indexing.
