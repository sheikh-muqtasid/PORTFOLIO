### Overview

QRPlate is a B2B SaaS platform designed to modernize the dining experience for restaurants. By providing QR-based digital menus and easy-to-manage systems, it eliminates printing costs and simplifies menu management without the complexity of traditional delivery systems.

**Technologies**: MERN Stack (MongoDB, Express, React, Node.js), Cloudinary, JWT  
**Project Type**: B2B SaaS / Digital Menu System

### Key Features

- **Dynamic QR Menus**: Instant menu updates via QR scan without reprinting physical materials.
- **Admin Panel**: Dedicated dashboard for restaurant owners to manage items, categories, and pricing.
- **Real-time Updates**: Changes are reflected instantly without requiring customers to download an app.
- **Mobile-First Design**: Responsive interface optimized for a seamless customer experience on smartphones.
- **Performance Optimized**: Built for fast loading times and high accessibility.

### Role & Contributions

- **Full-Stack Development**: Engineered the core menu management system from frontend UI to backend REST APIs.
- **System Architecture**: Designed a scalable architecture supporting multiple restaurants and branches.
- **API Development**: Built robust REST APIs with JWT authentication for secure owner access.
- **Public Menu Delivery**: Leveraged Next.js Server-Side Rendering for SEO-optimized and fast-loading public menus.

### Impact

- **Operational Efficiency**: Drastically reduced menu printing costs for early pilot restaurants.
- **Real-world Usability**: Focused on solving local pain points by providing a zero-install solution for both owners and customers.
- **Scalability**: Architecture designed to support growing numbers of restaurants with optimized database performance.
