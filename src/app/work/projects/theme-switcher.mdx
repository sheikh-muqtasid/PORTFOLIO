### Overview

A dynamic theme switcher component for modern web applications, allowing users to toggle between light and dark modes seamlessly, enhancing personalization and accessibility.

**Technologies**: React.js, CSS, Context API, Hooks  
**Project Type**: Web UI Enhancement / Frontend Component

### Key Features

- **Smooth Toggling**: Instant and elegant transitions between light and dark themes.
- **Global State**: Managed using React Context API for persistent theme selection across components.
- **Visual Appeal**: Responsive and visually appealing UI for better user experience.
- **Modular Design**: Modular, reusable component design for easy integration into any React project.

### Role & Contributions

- **Component Engineering**: Developed React components with focus on clean architecture and reusable code.
- **State Architecture**: Managed global theme state with Context API and modern Hooks.
- **Modern Aesthetics**: Styled the component for modern, professional aesthetics.
- **Responsive Behavior**: Ensured accessibility and responsive behavior across devices.

### Impact

- **Personalization**: Improved user personalization and engagement on web applications.
- **Modern UX**: Delivered a sleek, modern UX feature that enhances overall application appeal.
