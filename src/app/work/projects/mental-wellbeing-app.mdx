### Overview

A comprehensive mental wellbeing mobile app designed to help users manage stress, anxiety, and depression. The app provides guided sessions, interactive exercises, and daily routines to promote mental health and self-care.

**Technologies**: Flutter, Firebase, SharedPreferences, REST API  
**Project Type**: Cross-Platform Mobile Application

### Key Features

- **Dynamic sessions**: Tailored questions based on individual user needs.
- **Stress-level tracking**: Evaluation after exercises to monitor progress.
- **Daily routines**: Habit tracking and logging to support mental health improvement.
- **Persistent storage**: Seamless user experience across sessions using SharedPreferences and Firebase.
- **Modern UI**: Clean, intuitive, and responsive design for enhanced engagement.

### Role & Contributions

- **Frontend Development**: Designed and developed Flutter front-end components for all interactive sessions.
- **Backend Integration**: Integrated Firebase for real-time data storage and retrieval.
- **State Management**: Implemented logic to handle dynamic questions and responses.
- **UX Optimization**: Ensured mobile responsiveness and smooth UX across devices.

### Impact

- **Personalized Care**: Enabled users to track and improve their mental wellbeing consistently.
- **High Engagement**: Delivered an engaging, interactive, and user-centric mobile experience.
