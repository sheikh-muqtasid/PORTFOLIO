### Overview

Serenity Speak is a comprehensive mental wellbeing mobile app designed to help users manage stress, anxiety, and depression. The app provides guided sessions, interactive exercises, and daily routines to promote mental health and self-care.

**Technologies**: Flutter, Firebase, Firestore, SharedPreferences  
**Project Type**: Cross-Platform Mobile Application

### Key Features

- **Dynamic sessions**: Tailored questions fetched from Firestore based on individual user needs.
- **Stress-level tracking**: Real-time user input validation and evaluation after exercises to monitor progress.
- **Daily routines**: Structured habit tracking and logging to support mental health improvement.
- **Persistent storage**: Integrated local storage to persist user progress and responses using SharedPreferences.
- **Modern UI**: Clean, intuitive, and responsive design optimized for mobile devices.

### Role & Contributions

- **System Architecture**: Built a session-based system with dynamic content delivery from Firestore.
- **Frontend Development**: Designed and developed Flutter front-end components for all interactive sessions.
- **Backend Integration**: Integrated Firebase and Firestore for real-time data storage and retrieval.
- **UX Optimization**: Ensured mobile responsiveness and smooth UX across devices.

### Impact

- **Personalized Care**: Enabled users to track and improve their mental wellbeing consistently.
- **Real-world Problem Solving**: Delivered an engaging, interactive, and user-centric mobile experience focused on mental health.
